CSE 6242 · Georgia Tech

CareerAtlas

Compares cities and roles by what a salary is really worth after prices and taxes.

  • Built an ETL pipeline that cleans and joins 1.4 GB of H-1B wage, price and metro data with pandas and DuckDB.
  • Links the same employer across filings with entity resolution (fuzzy name matching), checked by a 300-pair hand audit.
  • When no option fits, constraint relaxation tries every way to loosen the query (lower the wage floor, add metros) and returns the Pareto skyline: the trade-offs nothing else beats on both.
  • Counts an option only if it holds in all 6 year-by-wage scenarios; a breakpoint index (sorted lists per metro, heap merge) answers ~135× faster than brute force.
  • Runs fully in the browser with D3 maps; tests confirm the JavaScript and Python versions agree.
